# Data sources and estimate boundaries

Reviewed on 2026-11-08. A data source supports only the claims stated below; provider data is never used as evidence for a different service claim.

| Data | Source | Use and limitations |
|---|---|---|
| Worldwide place search and reverse geocoding | [Geoapify geocoding](https://apidocs.geoapify.com/docs/geocoding/), [autocomplete](https://apidocs.geoapify.com/docs/geocoding/address-autocomplete/), [service terms](https://www.geoapify.com/terms-and-conditions/) | Live autocomplete results provide names, coordinates, country code, city, category and provider attribution. A search result is not service coverage. The API key stays in the Worker. |
| Walking and road route geometry | [Geoapify Routing API](https://apidocs.geoapify.com/docs/routing/) | Local comparison geometry, distance and base route time are live Geoapify responses. A road route does not establish taxi or ride-hailing availability, fare, pickup time, safety, accessibility, or a passenger-transit route. |
| Airport directory | [OurAirports open-data download](https://ourairports.com/data/); [OurAirports data dictionary](https://ourairports.com/help/data-dictionary.html); [pinned source revision](https://github.com/davidmegginson/ourairports-data/tree/64af12951161ed52bc733eb4101224643c48850a) | The source is public domain and carries no accuracy/fitness guarantee. The checked-in server-only index is generated from `airports.csv` at revision `64af12951161ed52bc733eb4101224643c48850a`, SHA-256 `5754df21f25cb08d2def8a80b3eb609ddc52a4217afa8eb48280b6428c06e78f` (retrieved 2026-11-08). It retains 3,245 IATA-coded, scheduled-service large/medium airport records plus country, municipality, region, coordinates and type. It excludes closed, small, private, heliport, unscheduled, invalid-code and invalid-coordinate records. A 250 km same-country candidate radius prevents remote cross-country matches; airport presence is not flight availability. `node apps/api/scripts/generate-airport-index.mjs` regenerates the pinned dataset. |
| Traditional/modern PUJ fare reference | [PTV News report of LTFRB's September 28, 2026 fare guides](https://ptvnews.ph/ltfrb-releases-new-matrices-for-puv-fare-hikes-effective-sept-28/) | PTV reports traditional PUJ ₱14 for the first 4 km plus ₱2 per succeeding kilometre, and modern PUJ ₱17 plus ₱2.40/km. Wandr's conditional jeepney estimate rounds the road-distance input up to whole kilometres. It is not the distance of a verified jeepney route, and no stop or boarding instructions are supplied. |
| Regular taxi reference | [PTV News report of LTFRB's September 28, 2026 fare guides](https://ptvnews.ph/ltfrb-releases-new-matrices-for-puv-fare-hikes-effective-sept-28/) | PTV reports a ₱65 regular-taxi flag-down, ₱13.50/km and ₱2/min travel-time rate. The local demo applies those values to Geoapify's road distance/time and rounds to broad estimate bands. It is not a meter reading, taxi service check, or live quote. |
| Car and motorcycle estimate coefficients | Wandr demo model in `packages/shared/src/demo-estimates.ts` | Centralized demonstration assumptions, versioned `wandr-demo-estimates-1.0.0`, rounded to ₱10 estimate bands and five-minute time bands. They are not sourced provider prices, not Grab/Maxim/Green GSM quotes, and not assertions that a company or vehicle serves a location. |
| Air reference fare and duration | Wandr demo model in `packages/shared/src/demo-estimates.ts` | Distance-based deterministic PHP reference amounts and a great-circle cruise-time proxy plus a fixed planning allowance. Carrier multipliers are calibration assumptions, not PAL/Cebu fare data. No carrier schedule, nonstop route, connection, flight number, seasonal price or seat inventory is used. |
| Davao City boundary | [Davao City GIS portal](https://gismap.davaocity.gov.ph/); [OCPDC GIS data request](https://cpdoapps.davaocity.gov.ph/divisions/gis) | The existing approximate Davao coordinate rectangle is retained as a local demo boundary. It is not an administrative boundary, and country metadata takes priority for international classification. |
| Existing local Davao landmark aliases | Live Geoapify geocoding results, documented in `packages/shared/src/davao-landmarks.ts` | Seven aliases remain as reviewed place-search records. They are not routes, fares, transport services or airport directory data. |

## What is not integrated

Wandr has no authorized/live Grab, Maxim, Green GSM or airline price/availability integration; no verified Davao jeepney stop or route dataset; and no documented DC Bus tracker API/data reuse permission. No exact passenger journey, boarding/alighting stop, transfer, pickup or service coverage is claimed. The empty files `apps/api/data/fare-rules.json` and `apps/api/data/transport-routes.json` remain intentionally empty; estimates are isolated in the model functions and carry provenance. See [DATA_README.md](../apps/api/data/DATA_README.md).
