# Data sources and evidence

Reviewed on 2026-11-08. A source appearing below does not mean its data is used to fabricate route options. Only sources that support the specific claim are used in the product.

| Data | Source | Status, scope, and limits |
|---|---|---|
| Map style and basemap | [OpenFreeMap Positron](https://tiles.openfreemap.org/styles/positron); [OpenStreetMap attribution](https://www.openstreetmap.org/copyright) | Style URL returned HTTP 200 and rendered locally. Map tiles are not transit-route, service-availability, or fare evidence. MapLibre attribution control remains visible. |
| Named place search and reverse geocoding | [Geoapify Geocoding API](https://apidocs.geoapify.com/docs/geocoding/); [Autocomplete documentation](https://apidocs.geoapify.com/docs/geocoding/address-autocomplete/) | Worker adapter is implemented with worldwide search; location bias does not filter results. The API key was absent during this work, so no real named POI response was verified. Provider quota, terms, and attribution apply. |
| Walking/driving route geometry and steps | [Geoapify Routing API](https://apidocs.geoapify.com/docs/routing/) | Worker adapter is implemented for walk/drive GeoJSON, metric distances, legs, and step text. A provider route is road/pedestrian geometry only: it does not establish passenger service, taxi availability, fare, safety, or accessibility. No live route response was obtained because the key is unavailable. |
| Davao city coordinate boundary | None included | The Worker uses a coarse approximate coordinate rectangle. It is not an administrative boundary and can include/exclude edge locations. No verified boundary dataset is configured. |
| Existing Davao public transport and Davao Bus project | [City Government: DC Bus fleet arrives (2025-10-15)](https://davaocity.gov.ph/transportation-planning-traffic-management/dc-bus-fleet-arrives-in-davao-city/); [2026 Davao project factsheet](https://uncrd.un.org/sites/default/files/2026-04/2026estws_s8-philippines.pdf); [ADB Davao Public Transport Modernization Project](https://www.adb.org/projects/45296-006/main) | The City said interim DC Bus was intended as a free peak-hour service and said routes were still subject to LTFRB approval when published. The April 2026 factsheet gives future construction/operations milestones for the modernization project. These establish project context, not currently usable stop sequences, routing geometry, or a verified origin-to-destination public-transit journey. No route records are bundled. |
| Davao jeepney/bus fares | [LTFRB official site](https://ltfrb.gov.ph/); [PIA report on updated matrices (2026-09-28)](https://pia.gov.ph/news/luzon/ncr/ltfrb-reminds-puv-operators-drivers-to-display-updated-fare-matrix/) | LTFRB says updated fare matrices are to be displayed and made available through its site, and current media reports describe adjustments effective 2026-09-28. The current applicable, signed Davao route/mode matrix was not independently retrieved and verified against a primary file here. No fare value is used in the app. Older LTFRB matrices are not treated as current. |
| Davao taxi fares and availability | [LTFRB taxi fare decision (2024)](https://ltfrb.gov.ph/wp-content/uploads/2024/10/CN-2022-7433-Taxi-Fare-Increase-03-18-2024.pdf) | The 2024 ruling is no longer sufficient to assert current rates after 2026 provisional fare changes. It establishes neither present taxi availability nor a complete passenger ETA. No taxi fare or service option is used in the app. |
| Ride-hailing quotes, tricycle routes/rates, traceable jeepney routes/stops | No authorized live integration or accepted source dataset | Not implemented or claimed. No scraping, invented route, or sample fare is used. |

## Phase 4 data gap

No traceable route/stop/direction dataset and matching current fare evidence were found to support two repeatable Davao passenger journeys. The transportation comparison acceptance gate remains blocked. The next valid step is to obtain licensed/current route and stop records and the applicable LTFRB matrices from DOTr/LTFRB Region XI or the authorized operators, confirm effective dates and route direction, and field-check one or more sample corridors before adding versioned records. A generic driving route does not fill this gap.
