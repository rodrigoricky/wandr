# Data sources and evidence

Reviewed on 2026-11-08. A source below does not mean its data is used to fabricate route options. The app uses a source only for the claim that source supports.

| Data | Source | Status, scope, and limits |
|---|---|---|
| Primary map | [OpenFreeMap Positron](https://tiles.openfreemap.org/styles/positron), OpenMapTiles, OpenStreetMap | Production browser returned HTTP 200 for the style JSON, style metadata, sprites, glyphs, sampled vector PBF tiles, and `/maplibre-gl-worker.mjs`; WebGL rendered nonuniform map pixels on 2026-11-08. Visible attribution remains in the app. |
| Map fallback | [OpenStreetMap tile usage policy](https://operations.osmfoundation.org/policies/tiles/); [OpenStreetMap copyright](https://www.openstreetmap.org/copyright) | Used only after the primary style has emitted a resource error and has not reached a complete render after 8 seconds. Browser requests go directly to `tile.openstreetmap.org`; tiles are not proxied, prefetched, or bulk-downloaded. The policy requires visible attribution, browser Referer, and respecting cache headers. Availability is best-effort with no SLA; the fallback browser test used a simulated primary-style failure, received real OSM PNG tiles, and then recovered to OpenFreeMap after an online event. |
| Worldwide search and reverse geocoding | [Geoapify Geocoding API](https://apidocs.geoapify.com/docs/geocoding/); [Autocomplete documentation](https://apidocs.geoapify.com/docs/geocoding/address-autocomplete/); [Geoapify service terms](https://www.geoapify.com/terms-and-conditions/) | Production API returned live place results for Davao malls, a college, a university, a hospital, airport, Davao City Hall, and Paris/Tokyo/Sydney landmarks on 2026-11-08. | Walking/road route geometry | [Geoapify Routing API](https://apidocs.geoapify.com/docs/routing/) | Production Worker returned live Davao walk and drive route geometry on 2026-11-08. | TNVS/Grab/Maxim/Green GSM, tricycles, jeepney routes/stops, flights | No authorized source integration | No live quote/availability API or licensed current route/stop dataset is configured. Do not infer a ride from road distance, estimate trip fares from a national matrix alone, or create a flight schedule. These modes stay unavailable. |

## Transport-data gate

At least two repeatable passenger journeys need source-backed service coverage, ordered stops/direction, boarding/alighting points, walking connections, and current fare applicability. The City has a public DIBS tracker but not an identified public API or data license for integration; request the data and intended-use terms from the City GIS/Davao Bus office. LTFRB's current downloadable fare records must be matched to the precise vehicle/service and fare rule. Until those inputs are available and validated, the product stays a walking/road-baseline prototype and presents no made-up transit or provider estimates.
