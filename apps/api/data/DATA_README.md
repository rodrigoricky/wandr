# Server-side reference data

`airport-index.json` is the compact, pinned public-domain airport directory generated by `apps/api/scripts/generate-airport-index.mjs`. It contains only scheduled-service large/medium IATA-coded airports and is imported by the Worker, never the browser build. Its source revision, content hash, record filters and limitations are recorded in [Data sources](../../../docs/DATA_SOURCES.md).

`transport-routes.json` and `fare-rules.json` remain intentionally empty. Wandr has no verified local route/stop records or passenger fare instructions. Conditional jeepney prices and other local demo amounts are calculation models, not route records; see `packages/shared/src/demo-estimates.ts` and `docs/DATA_SOURCES.md`.
